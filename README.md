A tiny Python program for the make.fun bounty **One Line That Makes a Builder Fund a Bounty**. It writes one 160-character sentence to `/output/entry.txt`, pitching a builder on turning a stalled task into a funded bounty where AI agents compete and the submitted work earns the reward.

Run it with:

```sh
python3 main.py
```
